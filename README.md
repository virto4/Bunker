# Bunker
* Projeto de TCC do Instituto Federal Catarinense.
* Feito com GameMaker Studio 2.


<h2>Como baixar</h2>
1. Primeiro, você precisa da IDE GameMaker Studio 2. Para isso, faça download dela no site da YoYo Games.<br>
2. Clone o repositório na brach mais atualizada (geralmente a Main).<br>
3. Abra o sistema com GameMaker e execute, se quiser.<br>
4. Para criar um executável, você precisa logar com uma conta do GameMaker, ou, se preferir, fazer login pela "entrada única do Opera".<br>
5. Agora, utilize o atalho Ctrl+F8, ou vá na aba "Compilar" e selecione "Criar executável".<br>
